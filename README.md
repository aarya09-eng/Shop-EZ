# ShopEZ

ShopEZ is a full-stack storefront for browsing products, managing a cart, checking out, and tracking orders.

## Development

You need Node.js and npm installed locally.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
